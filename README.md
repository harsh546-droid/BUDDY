# BUDDY🎓
## The Ultimate Study Companion for Students

**Buddy** is an educational Android app designed to help B.Tech and School students access notes, previous year questions (PYQs), and study materials in one place. No more wasting time searching multiple websites!

---

#🚀 What does this App do?
* **Centralized Notes:** Provides organized study material for B.Tech (CSE) and School students.
* **Smart PDF Viewer:** Read notes directly inside the app without downloading external players.
* **Exam Prep:** Access Previous Year Questions (PYQs) and Test Series easily.
* **User Friendly:** Simple and clean interface for fast navigation.

---

### 🛠️ Tech Stack (How I built it)
This project focuses on **Rapid Application Development (RAD)** using No-Code tools with complex logic.

* **Platform:** Kodular (Visual Programming / Block Coding)
* Guest login system.
* **Database:** Airtable / Google Sheets (for managing PDF links)
* **Key Logic:** Used logical blocks for User Authentication, dynamic ListViews, and Data retrieval.
